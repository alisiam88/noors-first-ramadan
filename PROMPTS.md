# Noor's First Ramadan — image prompts for ChatGPT

Instructions for the image generator: work through the jobs below **in order, one image per job**.
For each job: generate the image, save it to the exact file path given, commit it to this repo
with the commit message given, then tick the job's checkbox in this file. Skip any job already ticked.

Use `reference/page01_reference.png` as the character and style reference for every page.

## Rules for EVERY coloring page (jobs 5–15 and 3-redo)

Children's coloring book page for ages 3–6. Tall portrait page, black and white line art only.

Characters — keep them identical to the reference on every page:
- **Noor**: cheerful girl about 5 years old, simple hijab, long dress.
- **Adam**: her little brother about 4, kufi cap, long thobe.
- **Mom**: hijab and long dress. **Dad**: short beard and thobe.
- **Grandma**: hijab. **Grandpa**: white beard and a walking cane.

Style: thick bold clean outlines, cute rounded chibi proportions, big friendly eyes, large simple
closed shapes that are easy to color, very few small details, generous white space around the edges,
pure white background. No shading, no gray, no gradients, no hatching, **never fill any area with
solid black**, no text, no letters, no numbers, no border. Never depict any prophet.
